Algorithm Lab - installable offline app

1. Put this folder on any HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages),
   or test locally: run `python -m http.server 8000` in this folder, open http://localhost:8000
2. Open the URL once while online.
3. Install:
   - Chrome/Edge desktop: install icon in the address bar
   - Android Chrome: menu > Install app
   - iPhone Safari: Share > Add to Home Screen
After that it runs fully offline.
(Opening index.html directly from disk still works as a normal page, just not installable.)
